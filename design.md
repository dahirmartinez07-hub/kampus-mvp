
# design.md — Kampus

## 1. Identidad visual

Kampus es una aplicación de banca digital para estudiantes universitarios en México.

Su diseño debe transmitir:
- Confianza y seguridad.
- Simplicidad y claridad.
- Modernidad y juventud.
- Profesionalismo y accesibilidad.

La interfaz debe ser limpia, intuitiva y fácil de utilizar.

## 2. Paleta de colores

| Uso | Color | Código |
|---|---|---|
| Primario | Azul Kampus | #1D4E8F |
| Primario oscuro | Azul oscuro | #153B70 |

| Error | Rojo | #C8272E |
| Fondo | Gris claro | #F4F6FA |

| Texto principal | Azul grisáceo | #172B49 |
| Texto secundario | Gris | #718096 |
| Bordes | Gris claro | #DCE3ED |

## 3. Tipografía

- Fuente principal: Inter.
- Títulos principales: 31 px, negritas.
- Subtítulos: 20 px, negritas.
- Texto general: 14–16 px.
- Etiquetas: 13 px.
- Texto auxiliar: 11–12 px.

## 4. Componentes

### Botones
- Altura aproximada: 52 px.
- Bordes redondeados: 11 px.
- Acción principal en azul Kampus.
- Texto blanco y fácil de leer.
- Un solo botón principal por pantalla.

### Campos de entrada
- Altura aproximada: 49 px.
- Fondo blanco.
- Bordes redondeados: 10 px.
- Texto azul oscuro.
- Placeholders en gris.
- Errores visibles y fáciles de entender.

### Tarjetas
- Fondo blanco.
- Bordes redondeados: 22 px.
- Espaciado amplio.
- Sombras sutiles cuando sean necesarias.

## 5. Mensajes del sistema

- Éxito: utilizar verde (#128A5D).
- Error: utilizar rojo (#C8272E).
- Información: utilizar azul Kampus.
- Los mensajes deben explicar qué ocurrió y qué puede hacer el usuario.

## 6. Diseño adaptable

- Enfoque mobile-first.
- Ancho de referencia: 390 px.
- La interfaz debe adaptarse a pantallas pequeñas y grandes.
- Los botones deben ser fáciles de tocar.
- Evitar saturar las pantallas con información.

## 7. Confianza y transparencia

- Mostrar claramente qué sucederá después de cada acción.
- Informar sobre comisiones antes de confirmar operaciones.
- Permitir regresar o cancelar cuando corresponda.
- Mostrar estados de carga, éxito, error y contenido vacío.
- Las funciones simuladas deben identificarse como "Demo mode".

## 8. Principio general

Kampus debe sentirse como una aplicación financiera confiable, sencilla y moderna, diseñada para estudiantes universitarios.
